This repository contains D3.js examples for three interactive data visualizations:

1. **Force-directed graph** — nodes and links with draggable nodes.
2. **Sankey diagram** — a simple flow visualization.
3. **Hierarchical treemap** — nested rectangles sized by values.

## Files

- `index.html` — force-directed graph and navigation to the other visualizations
- `sankey.html` — Sankey flow diagram
- `treemap.html` — hierarchical treemap
- `GULSHAN_SINGH_LAB5.docx` — revised lab report

## Run locally

Open any HTML file in a modern browser. The pages load D3.js from a public CDN, so an internet connection is required.

## GitHub Pages
